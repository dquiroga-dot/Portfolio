# Neon Portfolio

A responsive, futuristic portfolio website built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — main portfolio page and all sections
- `style.css` — neon/futuristic visual design
- `script.js` — navigation, scroll animations and contact form
- `assets/cv.pdf` — placeholder for your CV

## Sections

1. Home
2. About Me
3. Resume
4. Certificates
5. Projects
6. 7HHEP
7. Contact

## How to use

1. Open `index.html` in a browser.
2. Replace `Your Name`, texts, certificates and projects with your information.
3. Put your real CV in `assets/cv.pdf`.
4. Change `hello@example.com` in `script.js` to your email.
5. Update LinkedIn/GitHub links in `index.html`.
6. Upload the folder to any static hosting provider or open it locally.

No build tools or frameworks are required.
